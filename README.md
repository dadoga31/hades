# HADES — Security Systems Manager

Aplicación PWA para la gestión de visitas técnicas y generación de presupuestos de sistemas de seguridad (CCTV, alarma, control de acceso, detección de incendio).

## Características

- Gestión completa de presupuestos de instalación
- Sistema persistente con localStorage
- Exportación a PDF profesional
- Diseño responsive (móvil y escritorio)
- PWA instalable

## Despliegue

Desplegado en Vercel como sitio estático. No requiere backend.
